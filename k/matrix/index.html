The 36 × 36 — a map of every game that could exist

If the game industry were born today, genre would not be a camera or a setting. It would be two questions: what does the player do (axis X), and what kind of system answers (axis Y). 36 × 36 = 1,296 cells. But nothing below is a game yet — each cell is only a name and a frame (~Frame: the three-block interface every game here is born into). Tap a cell, and the tap itself creates the game — at that moment, from that name and that frame. The game is saved as it is created (marked ✦), so it is created exactly once; after that, tapping simply opens it. And even then, only the first screen and its branches exist — the game grows one step ahead of the player, never more.
